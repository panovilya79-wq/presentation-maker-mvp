# Presentation Maker MVP

AI-скилл для OpenCode, который генерирует структуру презентации по заданной теме и аудитории.

## 🚀 Quick Start

1. Скопируй папку `.opencode/skills/presentation-maker/` в свой проект
2. Запусти OpenCode
3. Скажи: «Используй скилл presentation-maker. Сделай презентацию на тему [твоя тема] для [аудитория]»
